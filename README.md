# Renaissance Art Trainer

A single-page web trainer for freshman World History Renaissance art review.

Students can practice:

- identifying major Renaissance works by image
- matching works to artists
- connecting works to Renaissance centers such as Florence, Rome, Milan, and Venice
- reviewing approximate dates and themes

Live ChatGPT Site version: https://renaissance-art-trainer.dpobrien14.chatgpt.site

For GitHub Pages, serve `index.html` from the root of the `main` branch.
